# さすらいのモモンガカーニバル 🐿️

React + TypeScript + Vite で構築された個人サイト

## 機能

### 🎮 遊技場
- **御神籤ルーレット**: 運試しゲーム
- **弾幕ゲーム**: シューティングゲーム

### 🐦 大広間
- 投稿・いいね機能付きのシンプルな掲示板
- 投稿は24時間で自動削除

### 📁 宝物庫
- ファイル・テキストのお気に入り管理
- データのエクスポート・インポート

### 🏪 売店（MOMOStore）
- ゲーム内通貨「MOMOPay」でアイテム購入
- テーマ・機能の拡張アイテム

### ⚙️ 設定
- **ダークモード**: 目に優しい暗いテーマ
- **モノトーンテーマ**: 完全な白黒テーマ
- **共有機能**: データの入出力
- **通知音**: ゲーム効果音のカスタマイズ

## 起動方法

```bash
# フロントエンド
cd apps/frontend
npm install
npm run dev

# バックエンド（URL短縮機能）
cd functions/url-shortener
npm install
npm run dev
```

## 技術スタック

- **フロントエンド**: React 18 + TypeScript + Vite
- **ルーティング**: React Router
- **スタイリング**: CSS（カスタムテーマ対応）
- **状態管理**: React Context + localStorage
- **バックエンド**: Cloudflare Workers（URL短縮）

## 特徴

- 📱 **レスポンシブデザイン**: モバイル・デスクトップ対応
- 🎨 **テーマ切替**: ダークモード・モノトーン対応
- 💾 **データ永続化**: localStorage使用
- 🎮 **ゲーム要素**: ポイントシステム・ガチャ機能
