# さすらいのモモンガカーニバル 🐿️

React + TypeScript + Vite で構築された個人サイト

## 機能

### 🎮 遊技場
- **御神籤ルーレット**: 運試しゲーム
- **弾幕ゲーム（演習林）**: 守護者として修行を積むシューティングゲーム
- **ミニ数独パズル**: 4×4数独で論理思考力を鍛える
- **記憶力ゲーム**: 神経衰弱風カードゲーム

### 🏛️ 広場
- **大広間**: 投稿・いいね機能付きのシンプルな掲示板（1時間で自動削除）
- **公会堂**: モモンガくんとのAIチャット（完全ローカル動作）

### 📁 宝物庫
- ファイル・テキストのお気に入り管理
- 画像・動画・音声ファイル対応
- プレビュー機能付き

### 🏪 売店（MOMOStore）
- ゲーム内通貨「MOMOPay」でアイテム購入
- テーマ・機能の拡張アイテム
- 装備売却機能

### 🌳 木の洞（個人エリア）
- **森の記録帳**: ゲーム、ソーシャル、コレクション、特別実績
- **森の日課帳**: 毎日更新される挑戦課題・連続ログインボーナス
- **森の衣装部屋**: アバターカスタマイズ・コスチューム管理

### 🌰 どんぐり銀座（経済エリア）
- **MOMOBank**: 預金（1%/日利息）・投資・融資サービス
- **森の宝物庫**: ファイル・テキスト保存（プレビュー機能付き）
- **経済イベント**: デイリーボーナス・セール・特別キャンペーン

### ⚙️ 設定
- **一般設定**: ダークモード・モノトーンテーマ・データ管理
- **共有設定**: JSONファイルでのデータバックアップ・復元
- **音声設定**: BGM・効果音の音量調節・ミュート

## 起動方法

```bash
# フロントエンド
cd apps/frontend
npm install
npm run dev

# バックエンド（URL短縮機能）
cd functions/url-shortener
npm install
npm run dev
```

## 技術スタック

- **フロントエンド**: React 18 + TypeScript + Vite
- **ルーティング**: React Router
- **スタイリング**: CSS（カスタムテーマ対応）
- **状態管理**: React Context + localStorage
- **バックエンド**: Cloudflare Workers（URL短縮）

## 特徴

- 📱 **レスポンシブデザイン**: モバイル・デスクトップ対応
- 🎨 **テーマ切替**: ダークモード・モノトーン対応
- 💾 **データ永続化**: localStorage使用
- 🎮 **ゲーム要素**: ポイントシステム・ガチャ機能
- 🏆 **実績システム**: 進捗追跡と報酬
- 📋 **デイリーミッション**: 継続プレイ要素
- 🔊 **音声システム**: BGM・効果音（Web Audio API使用）
- ✨ **リッチアニメーション**: CSS3・Framer Motion活用
- 🤖 **AIチャット**: 完全ローカル動作のチャットボット
- 🎯 **多様なゲーム**: パズル・記憶力・シューティング
- 💰 **活発な経済**: 銀行・投資・アバター・イベント
- 🌲 **森の世界観**: 秘密基地らしい階層化ナビゲーション
